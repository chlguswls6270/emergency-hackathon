# The Daily Hacker · 더 데일리 해커

**개인 프로젝트** — 신문 형태의 화면에서 해커톤·팀 구인·제출물과 리더보드를 탐색하는 웹 데모입니다.

- React·Vite·React Router·Framer Motion과 FastAPI를 사용합니다.
- 행사와 순위는 샘플 데이터이며 참가 내역·팀 생성·제안 등은 브라우저에 저장됩니다.
- 제안 기능은 실제 사용자에게 메시지를 발송하지 않습니다.
- 파일 업로드·다운로드에는 접근 제어, 서버 생성 파일명, 용량·경로 검증을 적용했습니다.

Vercel의 Root Directory는 실제 앱 폴더인 `daily-hacker`로 설정합니다. 배포 환경의 파일 저장소는 임시 공간이며, 개인별 파일 접근 권한과 영구 저장을 제공하는 서비스는 아닙니다.
